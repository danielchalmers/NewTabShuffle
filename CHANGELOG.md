# Changelog

All notable changes to NewTab Shuffle will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-26

### Added
- Initial release of NewTab Shuffle extension
- Random URL selection on new tab
- Options page for managing URLs
- Add, edit, enable/disable, and delete URLs
- Support for http://, https://, and file:// URLs
- Chrome Storage API integration for cross-device sync
- TypeScript-based codebase with strict type checking
- Vite build system
- Vitest test suite with 100% coverage of core logic
- VS Code configuration and recommended extensions
- Comprehensive documentation (README, AGENTS.md, CONTRIBUTING.md)
- MIT License

### Features
- Clean, minimalist UI design
- Inline URL editing
- URL enable/disable toggle
- Validation for URL format
- Error handling for missing URLs
- Manifest V3 compliance
